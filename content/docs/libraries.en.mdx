## Library ID

| Source | Shape |
| --- | --- |
| Git repository | `/owner/repository` |
| Website | `/websites/slug` |
| Uploaded documents | `/docs/slug` |
| Notion | `/notion/slug` |
| Nested library | `/websites/slug/sub-slug` (likewise under `docs` and `notion`, up to four levels) |
| Pinned version | `/owner/repository/version` |

A changed slug keeps a redirect, and the API returns the new Library ID.

Slugs under `websites`, `docs` and `notion` nest: `/websites/ethereum/whitepaper` is a library of its own, grouped under `/websites/ethereum` in the catalogue. An id resolves to the longest library that exists, and only what is left over is read as a version, so `/websites/ethereum/<version label>` still pins that version of `/websites/ethereum`. In access rules, `/websites/ethereum/*` covers that library and everything nested under it.

## Versions are immutable

Every version freezes the source digest, the parser version, the chunker version and the embedding model. Publishing is an atomic switch of `current_version_id`.

A query pins its version when the request starts, so **a refresh never mixes old and new chunks**. If a refresh fails, the previous version stays available.

## Build billing

Every build of a library you own (the first index and each refresh after it) is priced in API calls from the content it adds, debited from the period's plan allowance and then from the call pack balance:

```text
build cost = base fee + ⌈new tokens ÷ tokens per call⌉ + ⌈pages fetched ÷ pages per call⌉
```

Current rates are 1 call per build, 1 call per 20,000 new tokens and 1 call per 5 pages fetched. Pages count only for Website, llms.txt and OpenAPI sources; Git repositories, Notion and uploaded documents fetch none.

| Situation | Cost |
| --- | --- |
| Refresh of an unchanged source | No version, nothing billed |
| Failed build | Nothing billed |
| Only some sources changed | New tokens counted for the changed sources only |
| Rebuild forced by a platform upgrade of the parser, chunker or embedding model | Nothing billed |
| Version anchoring | Nothing billed |

Calls are debited only when the version publishes. The wizard and the Rebuild button show the most a build can cost on your plan before anything is queued; when your balance cannot cover the base fee the request is refused rather than queued into a build that can only fail. If the measured price turns out to exceed your balance mid-build, the build stops before embedding and, again, nothing is billed.

The size limit is a ceiling, not an allowance: a full 20 MB library costs roughly 250 calls, so filling five of them in one month exceeds the Free allowance. Each version's cost is shown in the library's version history, and the dashboard lists retrieval calls and build calls for the period separately.
