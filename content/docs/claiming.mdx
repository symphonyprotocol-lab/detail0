---
title: 认领知识库
description: 证明你控制来源，取得管理权与分成收款资格。
---

提交一个公开知识库**不等于拥有它**。所有权只能通过认领取得。

认领要回答的不是「你是谁」，而是「**你是否控制这个来源**」—— OAuth 只建立身份，不代表发布权。

## 验证方式

| 来源类型 | 方式 |
| --- | --- |
| GitHub 仓库 | 仓库权限校验（`admin` 或 `maintain`），备选 DNS TXT |
| Website、`llms.txt` | DNS TXT 记录，备选 well-known 文件 |
| 上传文档、OpenAPI、Notion | 不适用，创建者即所有者 |

<Callout type="warn" title="配置文件不授予权限">
在 `recall0.json` 里放公钥、Token 或任何声明都**不会**改变所有权。配置文件的可写范围与来源的控制权不等价 —— Fork、PR 和镜像站都能写那个文件。
</Callout>

## 认领后获得

- 管理权：编辑元数据、配置解析范围、手动刷新、暂停或删除、查看解析日志
- 发布者分成收款方资格
- 详情页展示归属

未认领的公开库不产生收益，收益也不追溯到认领之前。
