Re0 turns public documentation and private material you are entitled to use into **versioned libraries** an AI agent can search, retrieve and cite.

Querying is always two stages:

1. `resolve-library-id` — get candidates from a library name and what you are asking about
2. `query-docs` — query one library by an explicit Library ID

<Callout title="What you are billed for">
Billing counts successfully accepted API/MCP calls, not tokens. How many chunks or tokens come back never changes the price. Building a library of your own is priced in calls from the content it adds; see [Libraries and versions](/docs/libraries#build-billing).
</Callout>

## Ways in

| Entry point | For |
| --- | --- |
| MCP | Agents such as Claude, Codex and Cursor |
| REST API | Server-side integration |
| SDK / CLI | Thin client wrappers |

REST and MCP return **citable context** only; they do not write prose answers. The web playground is the one entry point that generates natural language, and every fact in it must bind to a chunk returned by that same query.
