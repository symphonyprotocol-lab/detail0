## Library ID

| 来源 | 形态 |
| --- | --- |
| Git 仓库 | `/owner/repository` |
| Website | `/websites/slug` |
| 上传文档 | `/docs/slug` |
| Notion | `/notion/slug` |
| 指定版本 | `/owner/repository/version` |

Slug 变更保留 Redirect，API 返回新的 Library ID。

## 版本不可变

每个 Version 冻结 Source Digest、解析器版本、Chunker 版本和 Embedding 模型。发布通过原子切换 `current_version_id` 完成。

查询在请求开始时固定 Version，因此**刷新期间不会混合新旧 Chunk**；刷新失败时旧版本继续可用。
